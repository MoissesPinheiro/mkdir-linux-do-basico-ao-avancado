# Comando mkdir no Linux — Do Básico ao Avançado

Material complementar da playlist **Comando mkdir no Linux — Do Básico ao Avançado**, do canal **Aprenda Linux BR**.

## 📚 Sobre a playlist

Esta playlist foi criada para estudar o comando `mkdir` de forma progressiva, começando pelos fundamentos e avançando para situações práticas e conceitos mais profundos do Linux.

O objetivo não é apenas decorar comandos, mas compreender:

- o que o `mkdir` faz;
- como diretórios são criados;
- como caminhos funcionam;
- como combinar o `mkdir` com outros comandos;
- como o Bash interpreta operadores e expansões;
- como permissões interferem na criação de diretórios;
- como tratar erros;
- como utilizar `mkdir` em scripts e automações;
- e como a criação de um diretório chega até o kernel e o filesystem.

## 🐧 Ambiente utilizado

Os exemplos da playlist consideram principalmente:

- Linux;
- Ubuntu;
- Bash;
- GNU Coreutils.

Quando houver diferenças importantes entre GNU, POSIX, Bash ou outros ambientes, elas serão explicadas durante as aulas.

## 🎯 Metodologia

A sequência utilizada durante os estudos será:

**O que é → Por que existe → Como funciona → Exemplo → Prática → Resultado**

O comando `mkdir` será sempre o protagonista.

Outros comandos e recursos do shell poderão ser utilizados para verificar, complementar ou automatizar uma operação iniciada pelo `mkdir`.

Exemplo:

mkdir projeto && ls
